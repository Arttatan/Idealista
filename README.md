# Квартиры Порту и Брага

Локальный просмотр объявлений Idealista. Сбор по-прежнему делает `idealista_watch.py` и пишет полную базу в `data/listings.json`.

## Запуск сайта

```bash
python serve.py
```

Откроется [http://127.0.0.1:8765](http://127.0.0.1:8765). Остановить — Ctrl+C.

Нужен Python 3 и пакет `openpyxl` (он уже используется сборщиком). Отдельной установки для сайта нет.

## Ставки аренды

Файл `data/rent_rates.json`.

- `municipalities` — €/м² по городу. Поставьте своё число в `eur_m2` и сохраните: сайт и Excel подхватят его без перезапуска логики, достаточно обновить страницу.
- `eur_m2: null` — опубликованной ставки Idealista нет. Оценка не считается, на карточке будет «низкая точность». Так и задумано: пустую ставку скрипт не заменяет окружной «средней».
- `areas` — более точная ставка района, если она есть в отчёте Idealista. `cities` ограничивает, к какому городу она применяется.
- `confidence`: `высокая`, `средняя` или `низкая`. От неё зависит ширина вилки.

Сейчас в файле индекс Idealista за октябрь 2026 (средняя цена объявлений долгосрочной аренды, не медиана договоров). Дата сверки — в поле `checked`. Формула и коэффициенты — в `rent_estimate.py`.

## Обновление объявлений

Idealista часто режет прямой запрос скрипта. Рабочий путь:

1. В браузере открыть поиск за последние 48 часов (тот же URL, что в `idealista_watch.py`).
2. Сохранить карточки в `data/fresh_cards.json`.
3. Запустить:

```bash
python idealista_watch.py merge_cards
```

Старые квартиры не удаляются. У новых проставляется свежая дата «Добавлено». Потом обновить сейф сайта (`publish_vault.py`) и сделать `git push`.

На сайте новые за 48 часов ярко подсвечены, с бейджем «новая», идут сразу после избранных и статуса «Интересно». Есть фильтр «Только новые». Поиск и фильтр цены — до 320 000 €.

## Ссылка для жены

Сайт по ссылке: https://arttatan.github.io/Idealista/

Он открывается паролем. Пароль в репозиторий не записывается: в интернете лежит зашифрованный файл. Жена открывает ссылку, вводит пароль и видит тот же список.

Пометки (статус, избранное, заметки) общие: оба видите одни и те же. Синхронизация идёт каждые несколько секунд после ввода пароля. После обновления сайта оба сделайте обновление страницы (Ctrl+F5).

Чтобы выложить свежий список, в той же папке:

```powershell
$env:IDEALISTA_PASSWORD = "тот же пароль"
python publish_vault.py
git add web/vault.json
git commit -m "Обновить список квартир"
git push
```

Через пару минут ссылка показывает новый список. Пароль тот же.

## Заметки

`data/user_notes.json` — статус, приоритет, визит, заметки, плюсы, минусы, причина отказа, телефон, избранное. Сайт сохраняет их сам. Повторный запуск `idealista_watch.py` этот файл не стирает и при сборке Excel переносит пометки в таблицу.

## Excel

Кнопка «Excel» на сайте или:

```bash
python idealista_watch.py excel
```

Первые семь колонок — ссылка, город / район, цена, оценка аренды, состояние, энергокласс, год. Они закреплены.
